# Comparison With UCINET 6.832

This report concerns Romney development version 0.1.1, using R 4.5.2 and
psych 2.6.3. Reference output was generated by UCINET 6.832 on May 9, 2026.
Each fixed input CSV has 36 respondents and 103 items. The binary,
multiple-choice and ordinal inputs contain 120, 106 and 110 missing responses,
respectively. The original CSVs and UTF-16 logs are unchanged.

All raw item frequencies in the categorical logs match the CSV inputs exactly.
Agreement matrices match at the logs' three-decimal precision. Factor and
competence discrepancies exceed rounding alone. The cause cannot be fully
established without inspecting UCINET's factor-extraction implementation.
The ordinal ratio is particularly sensitive to its small denominator; its
absolute difference is about 1.14335 (1.85% of UCINET's reported ratio).

## Coverage And Tolerances

Tests cover all 1,296 agreement cells, 36 competence scores and 103 answers
for each model, plus every categorical item frequency and weighted frequency.
Absolute regression tolerances are 0.00050001 for agreement, 0.01 for
competence, 0.025 for the first factor, 0.01 for the second factor, 0.1 for
categorical factor ratios and weighted frequencies, and 1.5 for the ordinal
factor ratio. Categorical keys must match exactly; informal means must differ
by less than 0.001. These are cross-software regression tolerances based on
the reference discrepancy, not confidence intervals or evidence of exact
numerical equivalence. Future factor-library changes should be investigated,
not accommodated by automatically loosening these tolerances.

The logs do not include posterior-probability tables or second-factor loading
tables. Their agreement with UCINET is therefore not tested. Formal
posteriors instead have independent mathematical and boundary-case tests.
The covariance key is a weighted vote, and the informal key is an
original-scale weighted mean, not a standardized regression factor score.
No independent ANTHROPAC reference output is bundled.

## Reproduction

Run `Rscript --vanilla data-raw/compare_ucinet.R` from the package source
directory. The script reads the original logs, checks table dimensions and
row order, fits the current source (not a previously installed package), and
writes these files:

* `ucinet-summary.csv`: model statistics, maximum errors, software versions,
  log dates and MD5 checksums of the fixed inputs.
* `ucinet-agreement.csv`: every respondent-pair comparison.
* `ucinet-competence.csv`: all respondent estimates and differences.
* `ucinet-answers.csv`: every item answer and status.
* `ucinet-frequencies.csv`: raw and weighted categorical frequencies.
* `sessionInfo.txt`: the environment used to produce the comparison.

The old import script converts external UCINET DL files; it does not
reconstruct the original simulations. Missing original seeds are a
provenance limitation. Do not overwrite these fixtures with newly simulated
data and assume that their UCINET logs remain valid.
